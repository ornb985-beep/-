# 预留的接口 · 以后要变强，从这几个口子进

**目的**：以后要接更强的信息源、更强的模型、更强的人格，
**不用重写这套东西**——从下面这几个口子进就行。

**这一份只写「口子在哪、怎么用」**。要不要接、什么时候接，老板定。

---

## 一、换脑子（已经能用）

**口子**：`.loop/roles/<名字>.env`

```bash
./loop.sh 接口 客服 deepseek       # 一个人换一家
./loop.sh 接口 执行层 deepseek     # 一整层换
./loop.sh 接口 测 客服             # 真打一次看通不通
```

每个员工独立：自己的会话、自己的工作目录、**自己的接口**。
换谁不换谁只有一条线：**判断力省不得，体力活可以省。**

**要加一家新的**：改 `scripts/lib.sh` 的 `provider_row()`，一行。
**表里只放查证过的**——凭印象加一家，用户照着配一次配不通，这功能就废了。

## 二、更强的信息源（还没接，口子已经留好）

现在查真实数据只有一条路：**联网搜索**。
这一条决定了信息质量的天花板——搜索搜得到的，别人也搜得到。

**要接更强的，从这儿进**：`lz_one()` 里那句「你这一轮要联网查真实数据」。

| 想接什么 | 从哪进 | 现在缺什么 |
|---|---|---|
| 付费数据库（行业报告、企业工商、专利） | 给「行研」单独配 MCP 或 API key | 选哪家、多少钱 |
| 平台官方数据（电商大盘、广告后台） | 给「增长」单独配 | 授权 |
| 论文 / 标准全文 | 给「行业专家」配，**直接解掉 A 类那条诚实红线** | 订阅 |
| 真人访谈 | **这个不是接口问题**，是要真去问人 | —— |

**接的时候只改那一个角色的环境，别动主流程。**
这就是"每人一个独立接口"这个设计真正的用处——
**换信息源 = 换一个人的配置，不是重写系统。**

**第三行值得单说**：`references/专家的认可度.md` 里写着一条诚实红线——
「读不到那些书的全文，只有目录和摘要」。
**接上论文/标准全文，那条红线就可以拆掉一半。**
这是目前最值钱的一个升级口。

## 三、人格层（老板亲自加，位置已经留好）

现在的输出**准，但冷**。像一份靠谱的分析报告，不像一个懂你的人说话。

**口子**：`./loop.sh 蒸馏` 那套机制现成的（现在用来蒸馏行业专家）。
**缺的只是"选谁"。**

```
分析层（已跑通，不许动）        表达层（待加）
拆解 / 分轻重 / 挖三层     →    怎么说得让他喜欢、接得住
出选择题 / 算可行性              幽默、张力、温度
      ↑                             ↑
  错了 = 结论错                错了 = 不好听
```

**加的时候守住三条**（写死，别商量）：

1. 表达层**不许改结论**
2. 不许动 `[事实] [推断] [猜测]` 的标记
3. 不许改 ★ 评级、不许增删选择题

**为了一句话说得漂亮，把不确定的说成笃定的——那是把猜测伪装成结论。**

## 四、镜子层（刚建好，还没真跑过）

**口子**：`roles-模板/人生导师.md` ＋ `./loop.sh 照镜子`

它现在只有一件工具：**把他自己说过的话摆在一起**（矛盾、重复的词、绕开的地方）。

**以后要变强，加的是"素材"，不是"洞察"**：

- 更长的对话历史（现在只有 `00-听到的.md` 那几百字）
- 他跨项目的记录（`references/判断档案.md` 里有他历次的判断）
- 老板要加的**深度心理学 / 对人的认知**

**注意方向**：变强 ＝ **给它更多他真的说过的东西**，
不是给它更多心理学理论。**理论多了只会让它编得更像。**

## 五、评分机制（临时版，一定要重做）

现在：`可行性 = 已验证的承重条件数 ÷ 总数`。

**这是个占位的东西**，五个毛病都记在 `第1步-路线图.md` 里，
最大的一个是：**"查清楚了多少"和"查清楚之后看起来怎么样"混在了一个数里。**

**在重做之前，这个数只当「查清楚了多少」看。**
