# 组织架构

**这张图的每一个框，下面都对应一条能真跑的命令。** 对不上的，就是还没建。

## 三层的权力边界

| 层 | 是谁 | 能做什么 | **不能做什么** |
|---|---|---|---|
| **决策层** | CEO | 唯一最终裁决、派单、招人、直连你、管钱 | 不做执行细节；🟥 高危必须上报你 |
| **参谋层** | 10 个专家 | 只出意见书（证据＋置信度＋反方论据） | **不决策、不指挥执行、不碰执行物料** |
| **执行层** | 执行总监 ＋ N 个员工 | 按派单干活、交付产物 | **不改目标、不擅自对外、不写公共文档** |

**参谋层和执行层之间没有线。** 专家不能直接指挥员工，员工也不向专家汇报——
**中间必须过 CEO。** 这不是官僚，是防止「一群 AI 互相附和，产出最低公约数」。

## 每个框对应哪条命令

### 看板（一眼看全）

```
./loop.sh 看板
```
从真实状态生成一个本地 HTML，双击就开：
**左边组织图**（在岗／封存／还没招）｜**中间群聊时间线**（谁对谁说了什么）｜
**右边派活台账 ＋ 钱花在谁身上**｜顶上九步进度和预算条。

**它只读状态、不写任何东西**——看板坏了不影响 loop 跑。
想刷新就再跑一次。没有服务、不用联网、不会挂。

### 你 → CEO

| 你要干的 | 命令 |
|---|---|
| 定目标、开项目 | `./loop.sh start "一句话想法"` |
| 在群里说话（所有人下次开口前都看得见） | `./loop.sh say "话"` |
| 看现在什么情况 | `./loop.sh status` ／ `./loop.sh explain` |
| 花了多少钱、谁最贵 | `./loop.sh cost` |
| 设花钱上限（不设就不给跑自动） | `./loop.sh budget 50` |

### CEO → 左分支（咨询参谋层）

| 动作 | 命令 | 说明 |
|---|---|---|
| **定专家团** | `./loop.sh 专家团` | **CEO 先定缺哪三块判断、要什么样的人、明确不要什么** |
| **找外部专家** | `./loop.sh 行业报告 "议题"` | 行业专家照作业单去找：A 体系≥3／B 操盘≥3／C 标杆／失败方 |
| **蒸馏** | `./loop.sh 蒸馏` | 把够格的真专家做成能单独提问的智能体 |
| **专家群讨论** | `./loop.sh 专家群 "议题"` | 依次发言，**后面的能反驳前面的** |
| 用完封存／起复 | `./loop.sh 封存 专家-X` ／ `起复` | 换行业时收起来，不删 |
| **会诊** | `./loop.sh 会诊 "议题"` | **CEO 自己点名该问谁（最多 4 个）** → 逐个咨询 → 综合裁决 |
| 单独问某个专家 | `./loop.sh ask 战略 "问题"` | 接着上次聊，有连续性 |
| 招／看人 | `./loop.sh hire` | 按两个分支列出来 |

**为什么不是"十个专家全问一遍"**：实测一次调用 $0.15~$8.20，十个人问一遍要几十美元，
而且大部分人对某个具体议题给不出增量意见。
**挑人本身就是判断力的一部分，把它自动化掉等于把判断推给了流程。**

### CEO → 右分支（裁决派单）

| 动作 | 命令 | 谁干的 |
|---|---|---|
| 裁决 | `./loop.sh ceo` | CEO：看数 → 裁决 → 组队 → 问责 |
| **把决策拆成每个人的活** | `./loop.sh 派单` | **执行总监** |
| **定今天每个员工做什么** | `./loop.sh 排班` | **执行总监** |
| 单独派一件活 | `./loop.sh 派活 竞品 "任务"` | 直接给某个员工 |
| 看谁手上有什么活 | `./loop.sh 台账` | —— |

### 交付回流 → CEO

| 动作 | 命令 |
|---|---|
| 验收（过了／打回，打回要写清怎么改） | `./loop.sh 验收` |
| 无人值守往下跑（预算封顶） | `./loop.sh auto` |
| 项目到头了，封存 ＋ 写复盘 | `./loop.sh close` |

## 五条铁律（写死在每个角色里）

1. **专家不许绕过 CEO 达成影响全局的共识**
2. **执行总监不许改目标**，目标要变回 CEO 裁决
3. **对外／资金／删除／不可逆 → 必须你确认**（红灯，永不下放）
4. **失败不许报成功，产物不在不许报交付**
5. **查不到就说查不到，禁止编造来源**

第 4 条是这套东西栽过 9 次的那个坑（跑过≠跑成了、勾了≠做了、通过了≠验了），
所以它不只是写在提示词里，**是在代码里硬查的**：派活跑完查交付文件在不在，
不在就记「没交东西」。

## 文件在哪、谁能动

```
docs/                所有角色【只读】。共同的事实基础，谁都不许偷偷改
  10-群聊.md         所有人读写。互相交流靠这个，你也在里面
  11-派工单.md       执行总监写
  12-排班.md         执行总监写
work/<角色>/         只有他自己。搜集的资料、草稿、交付物
references/          跨项目层。reset 清不掉
  判断档案.md        活过项目的唯一资产
.loop/               状态、日志、账单、角色定义（不进版本库）
```

**角色觉得 `docs/` 里哪份写错了**：写进交付物说明理由，让 CEO 判断，
**不许自己动手改**。

## 一个员工 ＝ 一个独立智能体（三样东西都是他自己的）

| 自己的 | 在哪 | 换了会怎样 |
|---|---|---|
| 会话 | `.loop/roles/<名字>.session` | 他只记得跟【他】说过的话 |
| 工作目录 | `work/<名字>/` | 交付物落他自己地盘，互不踩 |
| **接口** | `.loop/roles/<名字>.env` | **他用谁家的 AI、哪个模型、花谁的钱** |

```
./loop.sh 接口                看每个员工用谁家的
./loop.sh 接口 客服 deepseek   换一个人
./loop.sh 接口 执行层 deepseek 换一整层（参谋和 CEO 不动）
./loop.sh 接口 测 客服         真打一次，看通不通
```

**换脑子只影响他一个人**：调用他的时候那个 `.env` 在一个子 shell 里生效，
跑完就没了。已验证——同一次自测里，客服连的是 DeepSeek，
战略同时还在官方那条线上，钥匙也没串。

**换谁不换谁只有一条线**：判断力省不得，体力活可以省。
CEO 裁决、风控反证、战略、行研留官方；客服、竞品、内容、数据可以换便宜的。

**账要说实话**：走别家接口时，`cost` 里那几笔的美元数是 claude 按
**Anthropic 价目表**折算的，不是真实花费。台账第 5 列标了每笔走的谁家，
`cost` 和看板都会当场提醒。**不标出来，就是一笔看起来很正经的假账**——
那正是六条不许里的第 2 条。

这条有硬测试守着：`scripts/test-接口.sh`，每次 `check.sh` 都跑。
它不测"命令有没有报错"，测的是 **claude 这个程序真正收到的环境变量是什么**——
因为换接口最坏的失败方式不是报错，是**看起来换了其实没换**。

## 会话怎么分（这条是实测出来的）

| | 会话策略 | 为什么 |
|---|---|---|
| `ask` 问答 | **接着上次** | 这是对话，不连续就每次从头解释 |
| `派活` / `会诊` / `派单` / `排班` | **每次全新** | 一件活 = 一个自包含任务包 |

**干活为什么必须隔离**：十件活堆在同一个会话里，越干越贵，
而且第一件活里的错误假设会一直粘着往后走（判断漂移）。
**干活的持久化靠交付物，不靠"记住"**——已验证：隔离会话的角色，
照样知道上一件活交了什么，因为群聊和它自己的 `work/` 目录里有。
