## 一、终局定义（一句话）

一套每日自动扫描供需信号、把每条结论钉死到字符级可复算证据、对每个商机给出
**带覆盖保证的成功概率 + 仓位建议 + 止损线**、并用真实结果持续自我校准的商机操盘系统。

人只做三件事：**终审、访谈、拍板花钱。**

### 愿景的诚实版本

| 想说的 | 为什么不能这么说 | 实际能承诺的 |
|---|---|---|
| 全方位超越最牛创始人 | Hone Capital 实测：算法推荐项目融资率 40% vs 行业 16%，**但与其自身人类团队几乎持平** | 以顶尖水平**无限规模化**复制 |
| 把最赚钱机会全部把握 | 会给系统制造美化置信度、少报反证的动机 | 高胜率**反复下小注**，用真实反馈快速纠错 |
| 让人躺着赚钱 | 当营销话术可以；作内部 KPI 会污染决策质量 | 大幅降低决策负担与试错成本 |

**核心 alpha 不是准确率，是时间差和覆盖广度。**
EQT Motherbrain 的典型案例是提前 18 个月标记标的、成交价低约 15% ——
价值被换算成"提前多久""便宜多少"，而不是"判断多准"。

## 二、四道门（G0–G4）

这四道门既是"要达到的效果"，也是"正确率提高"的度量本身。
**没有 G0–G2，任何功能都只是更华丽的猜测。**

| 门 | 判据 | 依据 | 解锁 | 当前状态 |
|---|---|---|---|---|
| **G0 可复现** | `verify_scores` 双跑逐字节一致；同输入排序 100% 稳定 | 铁律 1 的自动检测器 | 允许给自己用 | ✅ **已通过** |
| **G1 有区分度** | ≥5 个品类间，剪刀差 M / 切换势能 / 成熟度 L 不塌缩成同一档 | 无区分度 = 指标废了，早发现早止损 | 允许给种子用户用 | ⬜ 需 Wave 0 真实数据 |
| **G2 比瞎猜强** | `BS < UNC`（即 `RES > REL`）且 `BSS > 0`，已解析样本 ≥30 | Murphy 三分解的硬判据 | 允许宣称"有效" | ⬜ Outcome 零条 |
| **G3 比人省** | 系统 top-10 实际成功率 ≥ 人工 top-10；或同等命中率下人工工时降 ≥50% | Hone Capital 的诚实基准 | 允许定价为决策工具 | ⬜ |
| **G4 有时间差** | 系统标记日 vs 进入公开榜单/媒体日，中位领先天数 >0 且逐季提升 | 核心 alpha 是时间差 | 允许宣称护城河 | ⬜ |

### G0 已经怎么验的

```bash
python -m unittest tests.test_reproducibility -v
```

包含一个**反向测试**：向计算层注入一个漂移函数后，断言 `verify_scores`
**必须**抛 `ReproducibilityError`。一个永远通过的断言等于没有断言。

外加一条 AST 静态检查：`oic/scoring/` 下任何模块 import
`random / time / datetime / secrets / uuid` 即测试失败。

## 三、三条不可违背的铁律

### 铁律 1：确定性计算与 LLM 判断物理隔离

```
公式（剪刀差、Brier、机会分、评分、仓位）→ 本地代码，永不经过 LLM
判断（这条证据算不算、痛点真不真）      → LLM
```

依据：LLM 即使 `temperature=0` 也不保证可复现（浮点/硬件/provider 批处理）。

**落地**：`oic/scoring/` 与 `oic/calibration/` 零第三方依赖、零网络、零时钟。

### 铁律 2：先做单 agent 基线，别一上来堆集群

Google + MIT（Kim et al., arXiv:2512.08296）的 **45% 规则**：
单 agent 准确率超过约 45% 后，加 agent 收益递减甚至转负。
同研究实测顺序推理任务多智能体**倒退 39–70%**；并行任务（Finance Agent）
Centralized 架构 +80.8%。最优规模 **3–4 个 agent**。

**5 个各 95% 可靠的 agent 串联 = 系统可靠性仅 77%。**

**落地**：`oic.config.AgentGate.multi_agent_allowed()` 在
`baseline_accuracy is None` 时**永远返回 False**。没测基线就扩集群，
在代码层就走不通。

### 铁律 3：验证 agent 必须独立上下文

Chain-of-Verification（Meta AI, arXiv:2309.11495）的 **factored 变体** ——
验证问题独立回答、不看原草稿 —— 效果最好：长文本 FactScore 55.9 → 71.4；
list QA precision 0.17 → 0.36。

多智能体辩论存在**从众效应**（弱模型仅纠正 3.6% 立场偏差）。
**Challenger 不得看到 Analyst 的结论，只看原始证据。**

## 四、系统分层

| 层 | 内容 | LLM | 当前 |
|---|---|---|---|
| **L0 合规内核** | 数据源白名单、证券拦截、AI 双标识、审计日志 | 无 | ✅ 已实现 |
| **L1 采集层** | 供给侧/需求侧/社媒/先行指标 | 便宜档 | ⬜ 待法务放行 |
| **L2 证据层** | span-grounding、实体解析、真值发现、时效衰减 | 中档 | ✅ 核心已实现 |
| **L3 分析层** | Analyst / Dissector / Challenger / Pre-mortem / Steelman | 强档 | ⬜ 待基线测量 |
| **L4 计算层** | 全部公式 + 聚合 + 共形 + Kelly | **无** | ✅ 已实现 |
| **L5 校准层** | Brier/Murphy、分层贝叶斯、代理双通道、特征回归 | 无 | ✅ 核心已实现 |
| **L6 操盘层** | EVSI、老虎机、组合、止损/加仓、窗口倒计时 | 无 | ⬜ 待 Outcome |
| **L7 人机层** | 终审工作台、分歧高亮、不确定性可视化、小程序 | 强档 | ⬜ |
| **L8 工程层** | golden set、三级 eval、CI 门禁、分层路由、可观测性 | — | ✅ 骨架已实现 |
| **L9 商业化** | 定价、席位、引流工具、支付备案 | — | ⬜ |

**注意分层顺序**：L4/L5/L0 完全不依赖数据源采购与 LLM，所以先做完了。
L1 卡在法务，L3 卡在基线测量，L6 卡在 Outcome —— 这些**不是工程问题**。

## 五、这套设计能保证什么，不能保证什么

**能保证**：可复现、可审计、不自欺。
- 同一输入永远同一输出，且每个分数可展开成一行算式
- 每条数值证据都在原文里字符级验证过
- 样本不足时系统**拒绝输出**，而不是给一个看起来精确的数字
- 触及具体证券的措辞在输出层被硬拦截

**不能保证**：预测准。

准不准要等 G2 跑出来才知道，而那需要真实数据，**不需要更多功能**。
