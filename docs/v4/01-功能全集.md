## L4 · 计算层（纯代码，零 LLM）✅ 全部实现

| ID | 功能 | 落点 | 说明 |
|---|---|---|---|
| F4.1 `[v3]` | 四维评分引擎 | `scoring/dimensions.py` | 需求强度 = C×0.5+D×0.5；可行性 = O×0.4+E×0.4+资源×0.2；总分对半开。**资源系数恒为 0.2，永不被学习稀释** |
| F4.2 `[v3]` | 供给侧引擎 | `scoring/supply.py` | 剪刀差 M、死亡率 X、风险系数、M 系数分档、Schwartz L1–L5 自动定级。**存续企业数为 0 时报错而非返回 1.0** |
| F4.3 `[v3]` | 切换势能 | `scoring/switching.py` | `(推力+拉力)−(焦虑+惯性)`，≤0 一票否决。含忍受/焦虑/惯性三套词典，同条文本重复词不刷分 |
| F4.4 `[v3]` | 差异化 | `scoring/differentiation.py` | Ulwick 机会分（1–10 量表，结果 0–20）、Berger CS+/CS−、Kano 尖叫点判定、Q 率 >10% 判问卷无效 |
| F4.5 `[v3]` | 竞争格局 | `scoring/concentration.py` | HHI / CR4 / CR5 / CR8；份额和 >100% 报错 |
| F4.6 `[v3]` | 红线判定 | `scoring/redlines.py` | 五类红线，**归零用乘法不用分支**，与排序公式一致。满分商机 + 一条红线 = 0 |
| F4.7 `[v3]` | **verify_scores 双跑断言** | `scoring/engine.py` | G0 门。含反向测试与 AST 静态检查 |
| F4.8 `[新]` | **概率聚合器** | `scoring/aggregate.py` | **logit-pooling + extremization**（GJP 核心技术）。算术平均会系统性欠自信。分歧度（logit 标准差）>1.0 触发强制人审 |
| F4.9 `[新]` | **共形预测** | `scoring/conformal.py` | Split/Mondrian，distribution-free 有限样本覆盖保证。**样本不足时拒绝输出区间**——无保证的"90% 区间"比没有区间更危险。Mondrian 兜底时明确告知"仅剩边际保证" |
| F4.10 `[新]` | 贝叶斯分层校准 | `calibration/hierarchical.py` | Beta-Binomial partial pooling，纯标准库实现 Beta 分位数（连分式+二分） |
| F4.11 `[新]` | **Kelly 仓位（三重安全阀）** | `scoring/kelly.py` | ①只用 Wilson 下界不用点估计 ②硬上限 ¼ Kelly ③**样本 <30 直接拒绝输出**。Kelly 对胜率高估极敏感——高估 2× 会长期归零 |
| F4.12 `[新]` | 决策曲线分析 | ⬜ | 以决策收益而非预测精度作最终评价 |
