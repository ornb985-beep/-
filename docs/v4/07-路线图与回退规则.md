# 07 · 路线图、回退规则与已知失效模式

## 一、核心判断

**不要先把 L0–L9 建完再去找数据。**

先落"零依赖内核"（已完成），同时并行拿第一条真实数据。
因为内核不会被任何后续决策推翻，而没有数据的功能全是空转。

## 二、Wave 0–5

### Wave 0（第 1–2 周，零代码）🔴 **当前唯一该做的事**

| 任务 | 验收 |
|---|---|
| 手工跑 2 个品类完整流程 | 能否找出 ≥3 个"三重命中"痛点 |
| 5 个品类的剪刀差对比 | **是否塌缩成同一档（G1）** |
| 产出 Golden Dataset 种子 | 写进 `data/golden.seed.jsonl` |
| 数据源登记表过法务 | `source_registry` 至少 1 个源变 `cleared` |

**G1 是最早能证伪整套方法论的一道门。** 如果 5 个品类的剪刀差全落同一档，
供给侧引擎（本系统最大的差异化）就是废的 —— 越早知道越好。

**这批手工结果就是第一批标注数据，不要浪费。**

### Wave 1（确定性内核）✅ **已完成**

```

oic/calibration/  Brier/Murphy/分层贝叶斯/代理双通道
```

**验收 = G0：已通过**（含反向测试与 AST 静态检查）。

### Wave 2（第 7–10 周）：单 agent 基线 + 证据地基

前置：Wave 0 完成 + 至少一个数据源 `cleared`。

- 单 Analyst + Instructor/Pydantic 约束解码
- 接上已实现的 span-grounding
- 用 Wave 0 产出的 golden set 跑 eval

**验收：测出单 agent 准确率基线。**
这是铁律 2 的判据来源 —— **没有它就不该加任何 agent。**

### Wave 3（按 45% 规则决定）：验证层

**仅当基线 <45% 且任务可并行拆分**才做：
Challenger + Pre-mortem + Dissector + 概率聚合器 + Self-consistency。

代码层已强制：`AgentGate.multi_agent_allowed()` 在 `baseline_accuracy is None`
时恒为 False。

**回退规则**：多 agent token >15× 但质量提升 <20% → 退回单 agent + CoVe。

### Wave 4：校准与操盘

前置：**≥30 条已解析 Outcome**。

**第一件事必须是 F5.7 特征预测力回归**，不是最后一件 ——
在验证 C/O/D/E 有预测力之前，加任何高级算法都是在错的特征上做精算。

然后：共形区间接入 + 代理结局验证 + 组合/Kelly/EVSI + 领先指标发现。

**验收 = G2 + G4。**

### Wave 5：规模化与商业化

CATE 匹配度启发式 + 实体解析 + 小程序 + 支付 + 算法备案。

## 三、回退规则（触发即执行，不讨论）

| 触发条件 | 动作 |
|---|---|
| 多 agent token >15× 且质量提升 <20% | 退回单 agent + CoVe |
| 单 agent 基线 ≥45% | 不扩 agent，改优化提示词与验证 |
| 顺序推理任务 | 一律不扩 agent（实测倒退 39–70%） |
| span 丢弃率 >30% | 改抽取提示词/schema，**不放宽校验** |
| 重试率 ≥2 | 改 schema，**不加重试** |
| 5 品类剪刀差无区分度 | 停止建 L1 采集层，重新审视供给侧假设 |
| 代理结局 Prentice 不通过 | 停用该代理写入校准 |
| 污染检测误报 >真报 | 保持 `enabled=false` |
| 法务否决二手数据源 | "后悔信号"能力从蓝图中删除，不找替代性爬取方案 |

## 四、环境约束（实测）

本容器 `pip` 无法访问 PyPI，**无 pytest / numpy / scipy / sklearn**。

因此内核**纯 Python 标准库**实现：

| 需求 | 实现 |
|---|---|
| 测试 | stdlib `unittest` |
| Brier / Murphy | `math` + 四则运算 |
| 共形分位数 | 排序取下标（共形本质就是排序取分位） |
| Beta 分位数 | 连分式展开（Lentz）+ 二分 |
| 加权中位数 | 手写 |
| Causal Forest | **推迟到 Wave 5 有网环境** |

**这不是妥协，是收益：零依赖 = 五年后仍能原样跑通，
且 `verify_scores` 的可复现断言不会被第三方库的浮点行为污染。**

## 五、已知失效模式与残余风险

**这套设计不是万无一失的。** 按"会造成多大伤害"排序，
前三条是**结构性**的 —— 加再多先进算法也修不好。

| # | 失效模式 | 为什么加算法救不了 | 已做的缓解 |
|---|---|---|---|
| **1** | **地基未验证：C/O/D/E 四维从没被证明有预测力** | 共形预测、CATE、真值发现都是在**给定特征集**上做得更精确。特征集错了，它们只会把错的东西算得更自信 | F5.7 必须是 Wave 4 第一件事；在此之前所有权重标 `prior`，`uncalibrated_notice()` 强制界面显示"未校准" |
| **2** | **Outcome 零条 → 七个模块空转** | Brier/Murphy/BSS/分层贝叶斯/共形/Kelly/CATE **全部**需要真实结局 | 每个模块在样本不足时**拒绝输出**而非返回默认值：Kelly 返回 `refused=True`，共形返回 NaN 区间，Murphy 分解不计算 |
| **3** | **归因不可能：赚钱是系统还是执行力？** | 没有反事实。CATE 需要随机化才能识别因果，但你不可能"为做对照故意不给用户看好商机" | **只校准可验证的中间指标**（留资率、询单数、退货率），**不校准最终成败**。F5.9 已降级为"匹配度启发式"，禁止宣称因果 |
| 4 | 代理结局的 Goodhart 效应 | 优化 14 天留资率 ≠ 优化赚钱 | 双通道 + `assert_channel` 抛 PermissionError |
| 5 | Kelly 在胜率未知时会主动伤人 | Kelly 对胜率误差极敏感，高估 2× 长期归零 | 三重安全阀，且 ¼ 上限同时写进数据库 CHECK |
| 6 | **数据源合法性可能整体崩塌** | 若二手转卖不可抓 + 蝉妈妈/企查查按量太贵，则"后悔信号 + 剪刀差"两大差异化同时消失 | **Wave 0 必须先跑完登记表再写任何采集代码**。这是唯一能在花钱前测掉的致命风险 |
| 7 | 污染检测误报多于真报 | Benford 不适用于有价格分档的电商数据；突变点在大促必炸 | 三个检测器默认 `enabled=false`，需通过对抗集才可开 |
| 8 | 多 agent 可靠性乘法 | Pre-mortem/Steelman 在基线 >45% 时违背铁律 2。人的天性是把好东西全加上 | `AgentGate` 代码级门禁 + 单元测试断言 |
| 9 | **LLM 判断层的天花板 = 普通人** | ForecastBench：最强 LLM Brier 0.122 ≈ 普通公众 0.121，远不如超预 0.096 | 超过普通人只能靠**架构**，不能靠换模型。**含义：没有人的终审，系统达不到超预水平——"全智能"有硬上限** |
| 10 | 同质化自噬只是被推迟 | 限量席位卖光后：扩容=自噬回来，不扩=增长停滞 | 真正的解只有"卖方法论不卖结论"，但那要重写产品形态与定价。**这是产品决策不是技术问题**，本轮只预留字段 |

## 六、一句话结论

**这套设计能保证的是「可复现、可审计、不自欺」，不能保证「预测准」。**

准不准要等 G2（`BS < UNC`，样本 ≥30）跑出来才知道，
而那**需要真实数据，不需要更多功能**。

本轮实施的价值在于：把永远不会被推翻的那一层
（确定性计算 + 校准数学 + 合规拦截 + 数据契约）先固化成零依赖代码，
让后面每一条真实数据进来时都有地方落。
