# 08 · 操盘手全流程

本文档把「模拟顶级操盘手」的三段式框架定为系统主线。

```
① 全平台抓取 → 智能体分析过的、最全最真的数据
② 智能体分类分析 → 判断商业可行性
③ 回到操盘手 → 全套工具复审 → top3 的 BP + 90天执行 + 结果 + 人/钱/平台
```

---

## 一、两处诚实的偏离

框架我照做，但有两点必须说清楚，否则做出来的是幻觉。

### 偏离 1：不是「10 万条」，是「每一条都能指回原文字符」

**我踩过这个坑。** 上一轮我从检索摘要里手工转录数字，把「3.81万」记成
`3,810,000` —— 放大 100 倍。原因是我绕过了自己建的 `grounding.verify_claim`。

一个错的数量级会一路传导：剪刀差 → 排序分 → 仓位建议 → 商业计划书。
**没有 grounding 的 10 万条，比有 grounding 的 100 条更危险。**

所以数据主干改成：

| | |
|---|---|
| **主干** | 招股书（A 级：审计过、有法律责任），每份含数百个字段 |
| **补充** | WebSearch（B/C 级） |
| **硬约束** | 每个数字必须过字符级校验，对不上即丢弃 |
| **纠错** | `oic/research/audit.py` 六类确定性检查，扫全库 |

`audit.py` 就是「自动化分析纠错的智能体」——**但它不是 LLM**。
理由很简单：我犯的正是 LLM 那一层引入的错（摘要把「万」译成 million）。
让犯错者当裁判是无效的。六类检查全是可复现的算术与字符串比对。

### 偏离 2：不是「无信息盲区」，是「知道盲区在哪」

完备信息不可达。但**测量覆盖率**可达，而且直接影响决策。

上一轮回测的最大发现就来自这里：

```
as-of 2022 需求增速覆盖：9/17
as-of 2022 供给增速覆盖：2/17   ← 剪刀差算不出来
```

剪刀差是本系统最大的差异化。**它目前悬空**——不是因为没建，
是因为公开渠道拿不到供给侧数据。

若假装「无盲区」，这个结论就永远浮不出来。

## 二、三段式的实现映射

### ① 采集层

| 步骤 | 模块 | 拒绝条件 |
|---|---|---|
| 数据源放行 | `compliance/provenance.py` | 未登记 / 爬取 / 法务未过 → 抛错 |
| 取数 | `sources/fetchers.py` | 空响应视为错误，**不当作「无数据」** |
| 章节定位 | `sources/filing_parse.py` | 无标题行 → 返回空，不把整篇当一节 |
| 字段抽取 | 同上 | 数字对不上原文 → 丢弃 |
| 单位归一 | `research/units.py` | 跨币种转换标记有损并记汇率 |
| 口径判定 | `research/metrics.py` | 跨口径**拒绝合并**（份额≠规模，存量≠流量） |
| 多源合并 | `evidence/decay.py`、`truth.py` | <2 个 A/B 源 → 标「待核实」 |
| 全库纠错 | `research/audit.py` | 六类检查，有 error 即阻断评分 |

**招股书为什么值得单独建管线**：「行业竞争格局」是强制披露章节，
含市占率、CR5、同业企业数——正是公开渠道拿不到、而剪刀差必需的字段。
且它是 A 级（审计+法律责任），比行业报告高一个数量级。

登记为 `PUBLIC_DOWNLOAD`：法定公开披露，不是爬取。

### ② 分析层

**当前被铁律 2 阻塞**：`AgentGate.baseline_accuracy is None` → 禁止扩多智能体。

这不是保守，是算术：5 个各 95% 可靠的 agent 串联 = 系统可靠性 77%。
必须先测出单 agent 基线才能谈扩展。契约见 [04-Agent契约](./04-Agent契约.md)。

### ③ 操盘手复审层

已建好，零 LLM，全部可复算：

```
四维评分 → 供给侧剪刀差 → 切换势能 → 差异化 → 竞争格局
    → 五类红线（乘法归零，不可被高分抵消）
    → 排序分
    → 概率聚合（logit + extremization）
    → 共形区间 / Kelly 仓位（样本不足即拒绝输出）
```

### ④ 交付层

| 模块 | 产出 |
|---|---|
| `deliver/business_plan.py` | BP：机会论证 + **每条引用可追溯证据** + 风险 |
| `deliver/plan_90day.py` | 四阶段，每阶段带量化止损门槛与预算上限 |
| `deliver/resourcing.py` | 技能缺口（三技能模型）、分阶段预算、平台动作 |

导出前必过两道闸：证券边界 → AI 双标识。与其他输出路径一致，无例外通道。

## 三、「可预测的结果」怎么写

这是框架里最关键、也最容易变成骗人的一环。

### 为什么不给点值

已解析真实结局 **8 条**。在 n=6 时：

```
实测        ρ = −0.293
精确置换检验 p = 0.700     （穷举 20 种排列，非近似）
Bootstrap   [−0.905, +0.775]  大幅跨零
纯随机的 |ρ| 中位数 = 0.293   ← 与实测值相同
```

**观测值恰好等于噪声的中位数。** 在这个样本量上给出「90天GMV 42万元」，
无论标不标注置信度，都是编的。

### 改用的写法

```
若「7天留资率≥15%」（假设A）且「CAC≤80元」（假设B）且「退货率<15%」（假设C），
则第90天达成目标的先验概率区间为 12% 上下的宽区间。

反证条件：
  假设A —— 第7天留资 <50 → 痛点不成立，立即止损
  假设B —— 首轮 CAC >160元 且无下降趋势 → 渠道不成立
  假设C —— 退货率 >15% → 产品与预期不符，回到选品

三条中任意一条被证伪，上述区间即作废。
```

可执行、可证伪、不骗人。

## 四、为什么不能「再多测几个指标」

这是量化金融最贵的教训，也是本系统必须内建的护栏。

`oic/stats/overfit.py` 实测（n=8）：

| 试几个特征 | 纯运气能刷出的 95 分位 \|ρ\| |
|---|---|
| 1 个 | **0.655** |
| 5 个 | ~0.79 |
| 20 个 | **0.873** |

**在这个样本量下，试 20 个特征，纯运气就能刷出 \|ρ\|≈0.87。**

所以「我们又测了剪刀差、切换势能、HHI、成熟度，发现 X 最相关」
这类结论，在 n 变大之前一律不成立。

护栏三件套：

- `resample.py` —— 小样本可穷举的**精确**置换检验，不用正态近似
- `overfit.py` —— 运气基线、BH 多重检验校正、PBO 回测过拟合概率
- 回测报告自动打印上表，**每次都提醒**
