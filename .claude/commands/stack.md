## 先分清：这东西到底是什么形态

**不要默认它是软件。** 先判断属于哪一类，不同类走不同的路：

| 类型 | 例子 | 「做」指的是什么 | 「检查」指的是什么 |
|---|---|---|---|
| **软件** | 网页、App、小工具 | 写代码 | 跑测试、能打开 |
| **内容** | 视频、文章、课程、直播 | 写脚本、拍、剪 | 对照脚本清单和质量标准过一遍 |
| **服务** | 咨询、代运营、培训 | 定流程、写话术、做交付物模板 | 走一遍流程，看每步有没有卡点 |
| **实体/混合** | 带小程序的线下店 | 拆成上面几种分别做 | 分别检查 |

判断出来之后，在文档开头明写：「这个项目属于【X 类】」。
后面每一步都按这个来。**判断错了后面全是白工。**

## 一、这东西最终长在哪儿？

我打开它/接触它的时候，是在**什么地方**？把选项摆给我：

**如果是软件：**

| 形态 | 白话解释 | 适合什么情况 | 代价 |
|---|---|---|---|
| 网页 | 发个链接就能用，手机电脑都行 | 大多数情况的默认答案 | 得联网 |
| 手机 App | 从应用商店装 | 要用摄像头、要推送、要离线用 | 上架审核麻烦，成本高一截 |
| 电脑程序 | 双击图标打开 | 处理本地文件、数据不能上网 | 每台电脑都要装 |
| 命令行 | 敲命令用 | 只有你自己用，追求快 | 别人不会用 |
| 现有平台里的自动化 | 在你已在用的工具里加功能 | 团队已经在用飞书/企微/表格 | 受平台限制 |

**如果是内容：** 发在哪个平台？（平台决定长度、比例、开头几秒的打法、能不能挂链接）
必须查证该平台**当前**的规则和推荐机制——这些半年一变，别用老经验。

**如果是服务：** 通过什么渠道交付？（微信群、线下、腾讯会议、SOP 文档）

**先给推荐和理由**，理由必须落回 `00-目标.md` 和 `03-什么算好.md` 里写的东西，再让我确认。

## 二、用什么做

规矩：

1. **先查 `docs/01-巨人的肩膀.md` 里那份「现成轮子」清单。**
   能用现成的就绝不自己做。**每决定自己做一样东西，都要先说明为什么现成的不够用。**
2. **每个选择写四行**：这是什么（白话＋类比）、为什么选它、
   另一个选项是什么、什么情况下该换过去。
3. **优先选无聊的、用的人多的。** 你的任务不是炫技，是让这东西三年后还找得到人维护。
   想选小众新东西，必须给出强理由。
4. **能不写代码就不写代码。**

## 三、钱

一张表，价格**必须 WebSearch 查证**并写明查证日期：

| 项目 | 一次性 | 每月 | 免费额度 | 超了怎么收费 |
|---|---|---|---|---|

加一行合计。再加一段：「如果用的人涨到 10 倍，这个数变成多少」。
另外单列一行：**「哪些是可以随时停掉的，哪些是停不掉的」**——这决定了试错的成本。

## 四、怎么落地

从"做完"到"我能真正用上/发出去"，中间有哪些步骤，白话清单。
软件包括：域名要不要买、要不要备案、怎么更新、数据怎么备份、怎么回滚（回滚＝退回上个能用的版本）。
内容包括：发布时间、封面、标题、话题标签、发完怎么看数据。
服务包括：怎么收钱、怎么开票、出问题怎么补救。

## 五、画个图

用文字画一张，说明东西/数据/人从哪来、经过什么、到哪去。例如：

```
你的手机浏览器
     │  填了个表单
     ▼
  网页服务器  ──── 存 ────►  数据库（云上的仓库）
     │
     └──── 每天定时 ────►  发条微信提醒你
```

## 六、最后：建立「检查」的标准（这一步别跳）

自动循环靠 `bash scripts/check.sh` 判断做对没有。
它自己会认软件项目（有测试就跑测试）。但**如果这个项目不是软件，或者有软件之外的部分，
你必须在项目根目录写一个 `check.local.sh`**，把「怎么算做对了」变成机器能判断的检查。

例如内容项目：
```bash
#!/usr/bin/env bash
# 检查脚本文件在不在、时长够不够、必备元素齐不齐
set -uo pipefail
fail=0
[ -f 脚本/第1集.md ] || { echo "缺：第1集脚本"; fail=1; }
grep -q "前3秒钩子" 脚本/第1集.md || { echo "第1集没写开头钩子"; fail=1; }
exit $fail
```

**检查不了的东西，自动循环就管不了**，只能靠我肉眼看——
所以尽量把标准写成能检查的。实在检查不了的，在任务清单里标成「【停下来给我看】」。

---

写完告诉我：
1. 每个月要花我多少钱，其中多少是停不掉的
2. 最容易出问题的一环在哪儿
3. 如果做出来我不满意想推翻重做，损失多大（这决定了我们该多谨慎）

然后停下。**这一步涉及花钱，我不点头你不许往下做。**
