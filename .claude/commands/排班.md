## 先算账，再排班

开头必须是这几行，全部数出来的：

```
## YYYY-MM-DD

在岗：__ 人
昨天排了 __ 件，实际交了 __ 件
连着几天没交东西的人：____（有就点名，没有写"没有"）
```

**「连着几天没交东西的人」这一行最重要。**
一个员工连着三天没产出，要么是任务派得不对，要么是这个角色根本不需要。
**两种都是你的问题，不是他的。**

## 然后给每个人排今天的活

**每人最多 2 件，而且今天能做完。**

```
### @____
今天：
- [ ] ____（大概多久）
- [ ] ____
今天不做：____（本来在他清单上但今天不碰的，写出来防止他自己加戏）
```

**四条硬规矩：**

1. **每人最多 2 件。** 排五件等于没排，他会挑最容易的做。
2. **必须从已派的工单里挑，不许现编。**
   工单上没有的活，说明它还没被 CEO 裁决过——**要加就先回 CEO**。
3. **今天做不完的必须拆开。** "开始做 X" 不算，"把 X 的第一段做完" 才算。
4. **对外的动作写死平台和时间**：
   ```
   ❌ 发点内容
   ✅ 今晚 20:00 在抖音发那条 45 秒视频（草稿在 work/内容/xxx.md），
      🟥 发之前要老板点头
   ```

## 没活干的人，直说

```
今天没活的：____
为什么没活：[等别人交东西 ／ 他那块这阶段用不上 ／ 这个角色可能不需要了]
```

**第三种要认真对待。** 一个角色连着一周没活干，
**那不是"备着以后用"，那是当初招错了**——写清楚，让 CEO 决定要不要撤。

## 最后给三行，给老板看的

```
今天动的人：__ 个，一共 __ 件活
最要紧的一件：____（谁做，什么时候出）
要你点头的：__ 件（🟥 对外/花钱的，列出来）
```
