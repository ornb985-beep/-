# 你的活：把四份意见拧成【他能选的几个方向】

**不许把四份意见并排贴出来。** 那是四篇文章，不是一个决定。

四位各管一块，**同一个产品决定上，他们常常给出不同的答案**——
**那些打架的地方，就是真正的选择点。**

---

# 一、先找他们打架的地方（这一节最值钱）

```markdown
## 他们不同意的地方

### 分歧 1：____
- **美学大师**说：____（他的理由）
- **精神意识大师**说：____（他的理由）
- **这不是谁对谁错**，是两种不同的东西：选前者你得到 ____，选后者你得到 ____
```

**没有分歧是可疑的。** 四个人从四个角度看同一件事全都一致，
通常说明他们都在顺着同一个假设说话——**那个假设可能就是错的。**

---

# 二、拧成 2–3 个方向，每个都要有名字

**名字要他能记住、能复述给别人听。**

```markdown
### 方向 A · ____（一个他能记住的名字）

**一句话**：____

**这个方向的骨气是什么**：____
　（四位大师里，这个方向主要是谁的主张？为什么它成立？）

**长什么样**：____（挂真东西，能打开看的）

**关键的三个细节**（**具体到按钮**）：
1. ____　为什么：____　（哪位大师的判断，出处）
2. ____　为什么：____
3. ____　为什么：____

**代价**：____（必写。没代价的方向是假的）

**选了它，一年后用的人会说**：「____」
```

**「关键的三个细节」是这一步的硬要求。**
说不到按钮级的方向，等于什么都没说——
**"要有人文关怀"和"删除改成 5 秒撤销"，后者才是产品。**

---

# 三、最后只问他一个问题

**用户的全部工作量 ＝ 回答一个问题，或者做一道选择题。**

```markdown
## 我想问你一件事

### 问题 1：____
- **A** ____
- **B** ____
- **我推荐 ____**，因为 ____
```

**问场景，不问偏好。** 「你更喜欢哪种理念」他答不上来；
「这三个里，哪个是你愿意拿给你最挑剔的那个朋友看的」他答得上来。

---

# 四、说话

见 `references/怎么说话.md`。这一层特别要守的两条：

- **不许掉书袋。** 引一个人是为了让他更快做决定，不是显得有学问。
  **他不需要知道那个人是谁，只需要知道该选哪个**——
  出处放在括号里就够了
- **不许煽情。** 他要是觉得你在写文案，这一层就废了

写完用大白话跟他说三句：这几个方向差在哪 ／ 我最没把握的是什么 ／
需要你回答的那一个问题。**然后停。**
