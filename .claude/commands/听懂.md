## 第四样：读状态（这一节最容易做错，先看三条铁律）

**对人下判断，是 AI 最容易编、而且编得最像的一件事。** 所以先钉死三条：

### 铁律一 · 读「状态」，不读「人格」

| 可以判（状态，会变） | 一个字都不许写（人格，不会变） |
|---|---|
| 「他此刻上头了」 | 「他是个冲动的人」 |
| 「他在防御」 | 「他这种人就是听不进去」 |
| 「他没说出口的顾虑在钱上」 | 「他很抠」 |

**状态会变，标签不会。**
标签一旦写下，**会传染后面每一步的分析**——所以标签比状态危险十倍。

### 铁律二 · 每句心理判断必须指回原话，并带标记

跟痛点的规矩一模一样：**指不回具体某句话的，就是编的。**

```
✅ 他此刻在护着一个还没验证的决定 `[推断，依据："我已经想很久了"］`
❌ 这词是从别处听来的，他自己大概率说不清        ← 无标记、指不回原话，违规
```

**一句无标记的人物判断都不许有。**

### 铁律三 · 状态只许改「怎么问」，不许改「判什么级」

读出他上头了 → 下一道题先问止损。
读出他在防御 → 换个温和的问法。

**但是**：轻重（★／★★／★★★）的判级、`[事实]`／`[推断]`／`[猜测]` 的标记，
**一个都不许被状态读数改动。**

**这是分析层和表达层之间那道墙。** 顺着情绪说话可以，顺着情绪改结论不行。

### 怎么读：听到这些，别当字面意思

| 听到 | 别当成 | 翻译成 | 下一步怎么办 |
|---|---|---|---|
| 「没钱」 | 余额陈述 | 优先级：**不想为这个花钱** | 不辩论钱，去找价值没被看见的地方 |
| 「想明白再说」 | 拖延 | **他在等一个帮他想明白的人** | 别催。给一道选择题，不给一张表格 |
| 「除了X其他都行」 | 让步 | **X 是雷区**（利益／权力／面子） | 记下 X 绕开，不追问为什么 |
| 「你根本不知道什么情况」 | 抬杠 | 他有**没说出口的约束** | 停止推销，改问一个事实题 |
| 反复横跳 | 愚蠢 | 两个自己在打架：**想要 vs 怕失去** | 把两边的账替他摆出来，让他看见 |
| 突然不回复 | 拒绝 | 表格太大答不动／情绪没到 | 缩成一个问题，隔几天轻轻再碰 |

### 三条从人那儿来的规矩（照着办，不用理解）

1. **人考虑不了这么多点。** 永远不要求他"想清楚"——**替他想，他只确认**
2. **情绪先于道理。** 状态差的时候拿到的「不」不算数，**要隔几天二次确认，
   两次「不」才算真拒绝**
3. **第一口必须立刻有用。** 多数人要的是感觉不是价值，**不许说教**

## 「轻重」怎么判（这一节是这一步的核心）

**判断标准只有一条：这句话如果理解反了，会不会让后面全白做。**

会 → ★★★　　不会但有用 → ★★　　现在还轮不到 → ★

常见的判错：

| 他说的 | 容易判成 | 实际是 | 为什么 |
|---|---|---|---|
| 「做个小工具 / APP / 网站」 | ★★★ | **★** | 这是**形态**，第8步才定。现在定死等于跳过论证 |
| 「简单点就行」 | ★★ | **★** | 没有信息量。所有人都这么说 |
| 「像 XX 那样」 | ★★ | **★★★** | 他心里有个参照物——**那个参照物解决的是什么，才是他真正要的** |
| 「我总是忘记 / 每次都要 / 老是」 | ★ | **★★★** | 频次词。**痛点几乎都藏在频次词后面** |
| 「顺便还能……」 | ★★ | **★** | "顺便"是他自己都不确定的东西，别当承重墙 |

**没说出口的也要标。** 他没提"给谁用""谁掏钱"，那不是不重要，
是他默认了——**把那个默认写出来，标 `[猜测]`。**

## 「引导式」怎么落地

**用户的全部工作量 ＝ 回答一个问题，或者做一道选择题。**
他不用懂任何商业知识，不用想，不用做功课——那些是我们的活。
见 `references/用户只做一件事.md`。

**问题必须是选择题，不许是问答题。**

- ❌ 「你的预算是多少」——他答不上来，也答不准
- ❌ 「你想要什么样的体验」——这是把你该干的活推给他
- ✅ 「A：先做能立刻用的粗版，两周内你能拿去给客户试。代价是丑。
     B：先把样子做对，一个月后才能试。代价是这一个月你什么反馈都拿不到。
     我推荐 A，因为你现在最缺的是'有没有人真要'这个答案。」

**分清两种问题，给的东西不一样：**

| | 判断题 | 事实题 |
|---|---|---|
| 例子 | 「谁来定该回访了：固定周期／你自己标／按类型分规则」 | 「你的客户信息现在在哪：脑子里／excel／别的工具」 |
| 你知道什么 | 你懂利弊，只是他的偏好你不知道 | **只有他知道，你连猜的依据都没有** |
| 怎么给 | **必须给推荐项和理由** | **不许瞎推荐**，直说「这条只有你知道，它决定了____」 |

**给事实题硬编一个推荐，是把猜测伪装成建议**——比不推荐糟得多。

**状态读数在这里怎么用**：它只改**问法的温度和顺序**——
读出他上头了，就把"止损"那道题排前面；读出他在防御，就换个软一点的说法。
**它不改选项本身，不改推荐哪个，不改任何一条的轻重和标记。**

**另外两条铁律：**

1. **每个选项都要具体到能想象出画面**。选项之间必须真的不一样，
   不许出现明显没人会选的陪跑项
2. **只问决定方向的**。问不到方向的，你自己定，别烦他

## 什么时候可以写「状态：听懂了」

**同时满足才能写：**

- [ ] 每条 ★★★ 都挖到了第三层以上
- [ ] 真实痛点能**指回原话里的具体某句**，不是凭空说的
- [ ] 承重的判断里，没有剩下的 `[猜测]`（要么问过了，要么有原话作依据）

**不满足就老老实实写「还没听懂」，把问题问出来。**
听懂这件事上装懂，后面八步全部建立在一个误解上——
**那比多问一轮贵一万倍。**

## 到第 3 轮还没听懂

别硬凑。直接写：

```
状态：还没听懂
问了 3 轮还是没收敛。这通常不是问题问得不对，是这个想法本身还没成形。
```

然后给他三个选择：**A** 先做最小的一版看看真实反应　
**B** 换个更具体的切口重新说一遍　**C** 先放着，这事还没到时候。

# 最后

写完文件之后，用大白话跟他说三句，**别超过五行**：

1. 我听到你最想解决的是 ____
2. 我猜的、最可能猜错的是 ____
3. 现在最需要你回答的是 ____（指向第四节的问题）

**然后停。不要继续往下做，不要开始想方案。**
