# P1 · 免费数据抓取

> **能抓的是「站点允许你抓的」。** 这不是缩水版 —— 政府公开页、法定披露、
> 开放 API、RSS、允许索引的媒体页，绝大部分公开数据都在这条路上。

## 停止条件（先看这个）

| 信号 | 动作 |
|---|---|
| 源未登记或未放行 | 停。先走登记流程 [K-ACQ-001] |
| 源是 SCRAPING 类 | **永久停**，不找替代抓取方案 [K-ACQ-002] [K-GOV-025] |
| robots.txt 禁止 | 停 [K-ACQ-006] |
| robots.txt 5xx / 不可达 | **按禁止处理** [K-ACQ-007] |
| 返回 403 / 429 | **停，不重试、不换 UA、不换 IP** [K-ACQ-004] |
| 遇到验证码 / 指纹对抗 | 停。反爬是停止信号不是 bug [K-ACQ-003] |

## 步骤

### 1 · 登记源

填 `SourceRecord`：`access_method` / `tos_url` / `legal_status` /
`legal_note` / `reviewed_on`，涉个人信息的还要 `pipia_completed` [K-CMP-012]。

**默认全空是正确起点** —— 在填上授权依据之前，采集层本就不该能跑 [K-ACQ-001]。

优先级：
1. **法定披露**（SEC EDGAR / 巨潮）—— A 级，且不是爬取 [K-ACQ-026] [K-ACQ-018]
2. **政府公开**（统计局 / gsxt / 招投标）—— A 级 [K-ACQ-025]
3. **RSS**（36氪 / 虎嗅 / 亿欧）—— 发布方主动提供，合规位置最好 [K-ACQ-014]
4. **允许抓取的页面** —— 走 robots + 限速
5. ~~反爬站点~~ —— 不做 [K-ACQ-023]

### 2 · 配置取数器

```python
policy = FetchPolicy(user_agent="YourApp/1.0 (+mailto:you@example.com)")
```

UA 必须诚实：不含浏览器标识、必须带联系方式 [K-ACQ-005]。
构造时就会校验，伪装的 UA 根本构造不出来。

### 3 · 取数

四道闸依次过：白名单 → robots → 限速 → 条件请求。

- 限速取 `max(本方配置, 站点 Crawl-delay)` [K-ACQ-008]
- robots.txt 按 origin 缓存，别每页都拉 [K-ACQ-009]
- 带 ETag / Last-Modified，省对方也省自己 [K-ACQ-010]

### 4 · 解码与提取

- 解码失败**抛错**，绝不 `errors='replace'` [K-ACQ-011]
- 超限**抛错**，不截断 [K-ACQ-012]
- HTML 只去标签，**不做正文抽取** [K-ACQ-013]
- RSS 解析不出条目**抛错**，不返回空列表 [K-ACQ-015]
- 日期认不出**留空**，绝不填今天 [K-ACQ-016]
- 申报文件返回空**抛错**，不当作「该文件无数据」 [K-ACQ-017]

这六条是同一个道理：**静默的失败比吵闹的失败危险得多。**

### 5 · 招股书特殊处理

它是供给侧数据的最优公开来源 [K-ACQ-018]，但解析有三个坑：

- 软换行不能当句末 [K-ACQ-019]
- 章节标题必须是短行，否则在正文里误匹配 [K-ACQ-020]
- CID 字体要解 ToUnicode CMap [K-ACQ-021]

**已知偏差**：幸存者偏差 + 自利披露倾向，不能当客观事实直接用。
