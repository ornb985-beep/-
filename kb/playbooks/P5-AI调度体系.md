# P5 · AI 调度体系

> **多不等于准。** 集群只在可拆成独立子任务时有效。

## 停止条件

| 信号 | 动作 |
|---|---|
| 单 agent 基线未测量 | **不准扩集群** [K-ORC-002] |
| 单 agent 基线 ≥45% | 不扩 agent，改优化提示词与验证 [K-GOV-018] |
| 任务是顺序推理链 | **一律不扩** —— 实测倒退 39~70% [K-GOV-019] |
| 多 agent token >15× 且质量提升 <20% | 退回单 agent + CoVe [K-GOV-017] |
| 重试率 ≥2 | **改 schema，不加重试** [K-GOV-021] |
| span 丢弃率 >30% | 改提示词，**不放宽校验** [K-GOV-020] |

## 三条铁律

1. **确定性计算与 LLM 物理隔离** [K-ORC-001] ——
   LLM 只做一件事：给 C/O/D/E 四维打分。其余全是确定性计算。
   隔离是可复现性的**前提**，不是风格偏好。
2. **没有实测基线不准扩多智能体** [K-ORC-002] ——
   45% 规则；5 个 agent 各 95% 串联 = 77% [K-GOV-014]。
3. **挑战者必须有独立上下文** [K-ORC-003] ——
   factored CoVe，FactScore 55.9 → 71.4。

## 四级漏斗

| 级 | 做什么 | 用什么 | 成本 |
|---|---|---|---|
| L1 粗筛 | 不设限全量收集 | 检索 / RSS / 合规取数器 | search 配额 |
| L2 去重 | 查重 + 归一 + 信源折叠 | **纯程序，零 LLM** | **零** |
| L3 分流 | 按分数挑值得花贵配额的 | `select_for_escalation` | 零 |
| L4 精查 | 八角度调查 + 交叉求证 | 贵模型 / 集群 | llm 配额 |

[K-ORC-004]

**L2 必须零成本。** 把去重交给 LLM 既贵又不可复现 ——
同一批输入两次跑出不同结果，后面所有统计失去意义。

**低成本 AI 只能放 L2/L3 做归类，不能替代 L4 判断** [K-ORC-005]：
L4 输出会进 BP，而 BP 里每个数字都要过字符级 grounding。
省下的钱会在一次 100× 单位错上全赔回去。

## 成本与诚实

- 默认**不设上限**（`UNLIMITED = 2⁶²`），但**照常计数** [K-ORC-008] ——
  「花了多少 / 拿到多少」是饱和度判据的唯一输入
- 付不起就**如实标未处理**，不降标准、不假装评估过 [K-ORC-006]
- 宁可报少，不许凑数 [K-ORC-007]
- 漏斗自洽性在**启动时**炸，而不是线上第 13 次 [K-ORC-009] ——
  它抓到过 83 倍的真实矛盾

## 输出

三道强制闸门：**证券边界 → AI 双标识 → 标识校验** [K-ORC-010] [K-CMP-021]。
`export()` 是唯一出口 —— 做成唯一出口而不是「记得调用」，
是因为赶进度时一定会有人忘记。

**模型不做终审** [K-ORC-011]。LLM 判断层的天花板约等于普通人 [K-GOV-015]，
超过它只能靠架构 + 人的终审。

SDK 把纪律一起打包 [K-ORC-012]，`capabilities()` 让「还不能干什么」
可被程序读出 [K-ORC-013]。
