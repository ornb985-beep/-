# MoneyLoop · 使用说明书

> **一句话**：任何一个想法输入，都能快速得到一个诚实的答案——
> 要么变成赚钱闭环，要么在你花大钱之前告诉你它不行。

**这份是给你自己用的。** 想看给别人（合伙人／投资人）的介绍，看 `docs/项目说明书.md`。

---

> **第一次用？先看 [`安装与落地.md`](安装与落地.md)** ——
> 装在哪、怎么接 API、手机怎么办、系统全景图，都在那份里。
> 这一份是装好之后的日常使用手册。

# 一、五分钟上手

## 装什么

只要两样：

1. **Claude Code**（这套东西靠它干活）—— 装完在终端敲 `claude` 能出东西就行
2. **一个终端**（Mac 的「终端」、Windows 的 PowerShell 都行）

可选：`python3`（只影响看板，不装照样能跑）

## 开始

```bash
./loop.sh budget 50                     先设花钱上限，单位美元。这一步别省
./loop.sh start "我想做个帮我记客户跟进的小工具"
```

**就这样。** 剩下的它会带着你走，每一步都会告诉你下一句该敲什么。

## 卡住了怎么办

```bash
./loop.sh explain      用大白话讲一遍现在什么情况、我该干嘛
./loop.sh status       看进度
./loop.sh 看板         生成可视化看板，双击打开
```

**别硬试。** 卡住了就 `explain`，它会告诉你卡在哪、给你选择题。

# 二、九步流程：从一句话到能收钱的东西

```
1 目标  →  2 巨人的肩膀  →  3 共性与独特★  →  4 什么算好★
                                                    ↓
9 自动开做  ←  8 任务清单  ←  7 技术与落地★  ←  6 我不懂的  ←  5 要做什么★
```

**★ 是要你拍板的四步。** 划分标准只有一条：
**技术问题它自己定，生意问题必须你定。**

一直敲 `./loop.sh go` 就行，它会自己往下跑，到该你拍板的地方停下来。

| 步 | 它干什么 | 产出 |
|---|---|---|
| 1 | 把你随口一句话撑开：给谁、谁掏钱、**要赚多少钱、倒推算账** | `docs/00-目标.md` |
| 2 | 联网查前人做到最好的，带来源和日期 | `docs/01-巨人的肩膀.md` |
| 3 ★ | 共性守什么、独特赌什么 | `docs/02-共性与独特.md` |
| 4 ★ | **不问你标准，给你看 A/B/C，从你的选择里反推标准** | `docs/03-什么算好.md` |
| 5 ★ | 拆成第一版必须有／第二版再说／明确不做 | `docs/04-要做什么.md` |
| 6 | 找出你不知道但会踩的坑，用大白话讲 | `docs/05-我不懂的.md` |
| 7 ★ | 在哪落地、用什么做、**花多少钱怎么赚钱** | `docs/06-技术与落地.md` |
| 8 | 排成可勾选的任务清单 | `docs/07-任务清单.md` |
| 9 | 做→检查→修，循环到过关 | 真正的东西 |

**第1步的倒推算账是全套最狠的一道闸**：

```
一单赚多少 → 每月要多少单 → 要接触多少人 → 每天要多少人看到
→ 这个数字，靠你现在能想到的渠道，拿得到吗？
```

**大多数点子在这儿当场就死——不是想法不好，是算术不成立。**
一分钱不花、一天不等就能知道。

# 三、你的团队：一个 CEO ＋ 两个分支

```
        你（只跟 CEO 说话）
              │
         CEO（唯一拍板的）
        ┌─────┴─────┐
     咨询│           │派单
        ▼           ▼
   参谋层 10 人   执行总监 → 员工（销售/内容/竞品/客服…）
   只出意见       干活交付
```

## 招人

```bash
./loop.sh hire                     看有哪些人可招（按两个分支列）
./loop.sh hire 战略 财务 风控        招进来
```

**别一次全招。** 一次调用 $0.15~$8，十个人问一遍要几十美元。
**让 CEO 判断该问谁。**

## 用起来

```bash
./loop.sh say "我在想要不要把这个卖给别人"    在群里说话，所有人都看得见
./loop.sh ask 战略 "你怎么看"                  单独问某个人
./loop.sh 会诊 "议题"                          CEO 点名该问谁 → 逐个问 → 裁决
./loop.sh ceo                                  CEO 看数、裁决、组队、问责
```

## 派活干活

```bash
./loop.sh 派单                       执行总监把 CEO 的决策拆成每个人的活
./loop.sh 排班                       定今天每个员工做什么
./loop.sh 派活 竞品 "查清楚…"         单独派一件活，他会交一个文件
./loop.sh 验收                       CEO 逐份判行不行，打回要写清怎么改
./loop.sh 台账                       谁手上有什么活、到哪一步
```

# 四、外部专家：找真人的判断，不是让 AI 编

这是这套东西跟别的工具最不一样的地方之一。

```bash
./loop.sh 专家团                  CEO 先定：缺哪三块判断、要什么样的人、明确不要什么
./loop.sh 行业报告 "议题"          照单去找真人，一人一份落盘带出处
./loop.sh 蒸馏                    把够格的做成能单独提问的智能体
./loop.sh 专家群 "议题"            让他们依次发言，后面的能反驳前面的
./loop.sh 封存 专家-X              换行业了，收起来（不删，随时 起复）
```

**专家名单的配比是写死的：**

| | 至少几位 | 给什么 |
|---|---|---|
| **A 体系**（写书的、国家标准、行业规范） | **3，不许缺** | **知识骨架**：这行由哪些环节构成、标准做法是什么 |
| B 操盘（有可核对战绩的） | 3 | 什么条件下会失效 |
| C 标杆（乔布斯这类） | 0–2 | 判断范式（**别问他你这行的细节**） |
| 失败方 | 1 | 怎么死的 |

**为什么 A 类不许缺**：只按"有战绩"去找会找回一堆网红，
**有故事没体系，而且成功高度依赖那个年代的红利，拿到手没法用。**

**一条诚实红线**：它读不到那些书的全文，只有目录、摘要、书评、演讲。
所以每位都必须标明「我掌握到什么程度」——
**顺着目录编内容，是这件事最像模像样的一种编造。**

# 五、钱：这套东西会花钱，看得见才控得住

```bash
./loop.sh budget 50     设上限。没设就不给跑自动
./loop.sh cost          花了多少、哪一步最贵
./loop.sh auto          无人值守往下跑，撞到上限/闸门/卡点就停
```

**实测数字**（不是估的）：

- 一次调用 **$0.15 ~ $8.20**，差 50 倍
- 最贵的是第2步（联网大量查证）
- 问一个角色一句话，**全塞 8 份文档 $2.76，只给该看的 3 份 $0.68**

**所以：没设预算不给跑 `auto`。** 没上限的无人值守，
是一个你睡着之后还在花钱的东西。

# 六、看板：一眼看全

```bash
./loop.sh 看板
```

生成一个本地 HTML，双击就开：

- **顶部**：九步进度 ＋ 五个数（任务、要你干的、在岗人数、花了多少/上限、标准改过几次）
- **左边**：组织图（在岗／封存／还没招）
- **中间**：群聊时间线（谁对谁说了什么）
- **右边**：派活台账 ＋ 钱花在谁身上

**它只读状态、不写任何东西**——看板坏了不影响跑。想刷新就再跑一次。

# 七、随时能用的几个

```bash
./loop.sh judge      它给了个东西我不知道好不好 → 五个镜头互相打架，矛盾处才是决策点
./loop.sh correct    感觉哪儿不对 → 先查错在哪一层，再决定怎么改
./loop.sh explain    我忘了在干嘛 → 大白话讲一遍
./loop.sh today      今天该做哪 3 件事，顺便看这周到底动了没有
./loop.sh back       上一步方向就不对，退回去重做
./loop.sh close      项目到头了 → 封存 ＋ 写一份诚实的复盘
./loop.sh reset      全部清空重来（先自动备份）
```

  11-派工单.md            执行总监派的活
  12-排班.md              每天谁做什么
  13-专家团设计.md        CEO 定的专家团作业单
  99-结项.md              结项复盘（结项后才有）
work/<角色>/              每个角色自己的地盘，交付物在这儿
references/               ← 【跨项目的，reset 清不掉】
  判断档案.md             活过项目的唯一资产
  组织架构.md             每个框对应哪条命令
  框架库.md               思考工具（JTBD/蓝海/定价/分发…）
  判断标准.md             怎么判断好坏、怎么纠错

**谁能动什么**：`docs/` 所有角色**只读**，角色觉得哪份写错了要写进交付物让 CEO 判断，
**不许自己动手改**。`work/<角色>/` 只有他自己能动。

# 九、六条「不许」——这才是这套东西的真身

九步是外壳。**真正在起作用的是这六条：**

| | 不许什么 | 挡住的是哪种自欺 |
|---|---|---|
| 1 | **不许编** | 「业内普遍认为」——凭印象说出来的、听着很专业的话 |
| 2 | **不许把猜测当事实** | 一份读起来完美流畅、看不出哪句是猜的文档 |
| 3 | **不许问你答不上来的问题** | 「你的标准是什么」——把该它干的活推给你 |
| 4 | **不许只算一侧的钱** | 算了半天成本，从没问过谁掏钱 |
| 5 | **不许拿「我们更好」当护城河** | 功能更好／效率更高／更有品味 |
| 6 | **不许说通过了但其实没验** | 屏幕上全是 ✓，底下什么都没发生 |

第 6 条不只写在提示词里，**是在代码里硬查的**：
每一步跑完查该产出的文件在不在，不在就记「没做成」，不往下走。

# 十、常见问题

**Q：它跑一半停了，是坏了吗？**
先看它说什么。三种情况完全不同：
- 「不是代码坏了，是 AI 的额度用完了」→ **等就行，重跑没用**
- 「轮到你了，这条 AI 干不了」→ **该你上手了**，上面写了要你干什么
- 「这一步没有产出 XXX，按没做成处理」→ 看 `docs/05-我不懂的.md`，里面有选择题

**Q：能不能全自动，我什么都不管？**
**不能，而且不该。** 四个闸门定的是生意问题——凭什么是我们、什么算好、
砍哪个功能、花多少钱。**这些 AI 替你做只能靠编。**

**Q：贵吗？**
跑通九步大概 $20~40（实测）。跑之前用 `budget` 设上限，到顶自动停。

**Q：换个项目怎么办？**
`./loop.sh close` 结项写复盘 → `./loop.sh reset` 清空重来。
**`references/` 里的判断档案不会被清掉**——那是你攒下来的判断力。
