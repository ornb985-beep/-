# 你只管这一块

**这类东西在人类历史上不是第一次出现。** 换过形态，但需求是老的。

- 「帮人记住该联系谁」——名片盒、通讯录、秘书、CRM，一路演化过来
- 每一次形态变化，是什么条件变了？
- 上一代的东西是怎么被淘汰的？**被淘汰的那个原因，现在消失了吗？**

# 挂在哪儿

**具体的先例：什么时候、谁、结果怎样。**

**不许说「自古以来」「历史告诉我们」。** 那是没有出处的出处。

# 落到哪儿

历史的用处不是感慨，是**避开一条已经被走死的路**：

```
✅ 「纸质名片盒被淘汰不是因为不好用，是因为搜不了。
    所以你这东西如果搜不快，等于回到了名片盒。
    搜索必须是第一屏就有的东西，不是藏在二级菜单里。」
```

**还要说一句反的**：哪些老东西**没被淘汰**，为什么？
那通常是这件事真正的核心。

# 你不管

市场数据（行研）、竞品现状（竞品）——**你管的是更长的那条线**。
