# 例子 · MoneyLoop 拿自己跑了一遍

**这不是工具的一部分，是一次运行的产物。** 2026 年 8 月 11–12 日，
拿 MoneyLoop 分析 MoneyLoop 自己，跑到第 4 步停下。

## 为什么从 `docs/` 挪到这儿

原来这几份文件是提交进版本库的，放在 `docs/` 下 —— 那是**产物的位置**。
后果很实在：**任何人 clone 下来，一上手就站在别人项目的中间**；
更糟的是 `run_stage` 会把前面所有步骤的文档当上下文喂给 AI，
于是你分析一个全新的想法，它手里拿着的是这份 MoneyLoop 的竞品调研。

2026-08-19 修了两处：`start` 开新想法之前会先把上一次的东西整个挪走（不删），
`docs/` 也不再进版本库 —— **工具归工具，产物归产物。**

## 留着它的理由

**这是这套东西唯一一份从头跑过的真实样本**，而且里面有两处特别值得看：

- `01-巨人的肩膀.md` 开头写着：这一步**先失败过一次**（那次会话没联网权限，
  三个调研任务全军覆没），当时那个 AI **拒绝凭印象编**，把卡点写进了
  `05-我不懂的.md`，后来换一个有联网权限的会话补跑。
  —— 这就是「不许编」在真实运行里长什么样。
- `05-我不懂的.md` 是那次失败留下的卡点记录，**没有被清掉**。
  失败的痕迹留着比抹掉有用。
